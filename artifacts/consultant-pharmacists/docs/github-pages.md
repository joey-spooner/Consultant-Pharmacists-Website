# GitHub Pages setup

This repository includes a GitHub Actions workflow for the Consultant Pharmacists static site. It builds the site into `artifacts/consultant-pharmacists/dist/public` and deploys that directory to GitHub Pages.

The public page addresses are `/`, `/webinars/`, `/contact/` and `/cv/`. The unlisted call page is `/join/`. Terms of Sale are at `/terms/`, linked from the footer and purchase buttons. Only the first four addresses belong in the sitemap.

The implementation lives in `src/site/`, with `SitePage.tsx` as the page component. Earlier shared addresses are maintained as small, nonindexable redirect documents generated by `scripts/static-routes.mjs`; they are not additional website designs.

To publish it:

1. Upload/connect this code to your GitHub repository. The workflow runs on pushes to `main`; edit `.github/workflows/consultant-pharmacists-pages.yml` if your default branch has another name.
2. In the repository, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**.
3. Open **Actions**, select **Deploy Consultant Pharmacists to GitHub Pages**, and choose **Run workflow**. Later pushes to `main` deploy automatically.

The workflow uses GitHub's `configure-pages` outputs: its `base_path` supplies the repository prefix for project sites, and its `origin` supplies `SITE_URL` (including a Pages custom domain when configured). The default metadata domain is `https://consultantpharmacistsofamerica.com`. Set up any custom domain and DNS in GitHub Pages settings as needed; metadata alone does not configure DNS.

For a root-path build with the default domain, set `BASE_PATH=/` and leave `SITE_URL` unset. For a repository-path preview, pass the repository prefix through `BASE_PATH` and its host through `SITE_URL`. Both navigation and redirects retain that prefix.

Do not report a publication as complete based only on a successful local build. Wait for the Pages workflow to finish, then open the live pages and compatibility redirects on the URL returned by GitHub Pages.
